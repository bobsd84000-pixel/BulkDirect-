# Skills Reference

Packaged expertise and workflows for specialized tasks.

## Skill Categories

### Architectural Skills

**Plan Agent**
- Generate implementation plans
- Identify critical files
- Consider trade-offs
- Estimate complexity

**Usage:** `/plan "implement multi-tenant auth"`

---

**ADHD Mode** (Divergent Ideation)
- Parallel brainstorming
- Multiple cognitive frames
- Architecture decisions
- Fuzzy debugging

**Usage:** `/adhd "how should we structure the API?"`

---

### Frontend Skills

**Frontend UI Engineering**
- Build production UIs
- Responsive design patterns
- Component accessibility
- Dark mode support

**Usage:** `/frontend-ui-engineering "create checkout form"`

---

**Artifact Design**
- HTML/React artifact guidance
- Design system integration
- Layout and theming
- Browser compatibility

**Usage:** Auto-loaded when creating visual artifacts

---

### Code Quality

**Code Review**
- Bug detection
- Performance optimizations
- Simplification opportunities
- Security analysis

**Usage:** `/code-review --fix [branch]`

---

**Simplify**
- Reuse opportunities
- Efficiency improvements
- Code altitude cleanup
- Test coverage

**Usage:** `/simplify`

---

### Specialized Skills

**Security & Hardening**
- Vulnerability scanning
- Authentication review
- Data protection patterns
- OWASP top 10 checks

**Usage:** `/security-review`

---

**Dataviz**
- Chart design patterns
- Color palette selection
- Accessibility for graphs
- Dashboard layouts

**Usage:** Auto-loaded when creating charts

---

## Recommended for BulkDirect

1. **Plan Agent** - SaaS feature architecture
2. **Frontend UI Engineering** - Landing pages & dashboards
3. **Code Review** - Quality gates
4. **Security & Hardening** - B2B compliance

**Via CLI:**
```bash

claude skill install frontend-ui-engineering
```
