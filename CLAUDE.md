## Skills

### ADHD Skill

Parallel divergent ideation pour brainstorming architectural et décisions de design.

**Usage:**
- `/adhd` pour divergence complète
- "ADHD mode" ou "brainstorm this" pour invoquer
- Idéal pour: design decisions, API surface, naming, architecture, fuzzy debugging
- À éviter pour: syntax, lookups, bugs avec root cause connu

**Coût:** ~10 appels Agent, 30-90s, 5-10x une réponse simple.
